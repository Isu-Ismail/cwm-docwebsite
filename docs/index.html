Every command with its flags and the output the CLI really prints. Outputs were captured from the v2 binary and paths are shortened to C:\Users\you.

$ cwm --help

Getting started

  • cwm hello One-screen health check: version, OS, shell, history file, shell integration and database counts, followed by the cwm logo in half-block pixel art.
  • cwm setup Install the small shell function that lets `cwm get <name> -x` run in your current shell.
  • cwm version Print the installed CWM version.

Command vault

  • cwm save Store a command, a piece of history or a multi-line script under a short name.
  • cwm get Find a saved command, copy it, show it, or run it. Also searches shell history.
  • cwm clear Delete saved commands, wipe history, or restore from the trash.

History

  • cwm watch Install or remove a shell hook that records each command with its folder.
  • cwm tidy Remove duplicate commands from your history file and from the watch log.

System

  • cwm config Show or change settings: editor, copy bank folder, history file.
  • cwm bank See where CWM keeps its data, or delete it.
