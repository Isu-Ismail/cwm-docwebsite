Install cwm

One binary, no runtime. Pick your system, run the command, then check it with cwm hello.

  1. 1Download and install

    PS> Invoke-WebRequest -Uri https://github.com/Isu-Ismail/cwm-cli-go/releases/download/v2.0.0/cwm-cli_windows_amd64.zip -OutFile cwm-cli.zip; Expand-Archive -Path cwm-cli.zip -DestinationPath C:\cwm; Remove-Item cwm-cli.zip

    or download cwm-cli_windows_amd64.zip yourself.

  2. 2Add it to your PATH

    PS> [Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\cwm", "User")

    Open a new terminal afterwards so the change is picked up.

  3. 3Check that it runs

  4. 4Turn on shell integration

    $ cwm setup

    Adds one block to your shell profile so cwm get name -x runs in your current shell. See cwm setup.
